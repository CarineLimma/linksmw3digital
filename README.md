# 💜 Links MW3 Digital

### Página Web | HTML5 • CSS3

## 📖 Sobre o projeto

O **Links MW3 Digital** é uma página web desenvolvida para centralizar os principais links e canais digitais da MW3 Digital, empresa especializada no desenvolvimento de soluções tecnológicas.

O projeto tem como objetivo facilitar o acesso às informações da empresa, proporcionando uma navegação simples e uma apresentação alinhada à identidade visual da marca.

A aplicação foi desenvolvida utilizando HTML5 e CSS3, com foco na organização dos elementos, estilização personalizada e experiência do usuário.

## 🎯 Objetivo

Criar uma solução digital para reunir informações e canais de comunicação da MW3 Digital em um único ambiente, fortalecendo sua presença online e facilitando o contato com potenciais clientes.

## ✨ Características do projeto

- Página web personalizada para a MW3 Digital.
- Estrutura desenvolvida com HTML5.
- Estilização utilizando CSS3.
- Organização de conteúdos e elementos visuais.
- Utilização de imagens e recursos gráficos.
- Identidade visual alinhada à marca.
- Navegação voltada à apresentação dos canais digitais da empresa.
